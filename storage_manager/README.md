# Storage Manager (SM)

Implementasi oleh group SM (Group 1).

Facade: `StorageManager` di `common/interfaces/storage_manager.py`. Selama implementasi asli belum ada, komponen lain memakai `mocks/mock_storage_manager.py`.

## Requirement

| Kode | Judul |
| --- | --- |
| SM-01 | Menyimpan Data Secara Permanen di Disk |
| SM-02 | Menyimpan Tipe Data Integer, Float, Char, dan Varchar |
| SM-03 | Menyimpan Record dalam Format Internal |
| SM-04 | Mengambil Data Tabel |
| SM-05 | Menambah Data |
| SM-06 | Mengubah Data |
| SM-07 | Menghapus Data |
| SM-08 | Mengetahui Struktur Tabel |
| SM-09 | Mengetahui Statistik Tabel |
| SM-10 | Membuat Index (B+Tree/Hash) |
| SM-11 | Mencari Data Lewat Index |
| SM-12 | Mempercepat Akses Data dengan Buffer |
| SM-13 | Menulis Perubahan ke Disk |
| SM-14 | Menyediakan Basis Data Contoh |
| SM-15 | Driver Program Komponen |
