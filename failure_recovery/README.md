# Failure Recovery Manager (FRM)

Implementasi oleh group FRM (Group 2).

Facade: `FailureRecoveryManager` di `common/interfaces/failure_recovery.py`.

## Requirement

| Kode | Judul |
| --- | --- |
| FR-01 | Mencatat Perubahan Data ke Log (WAL) |
| FR-02 | Mencatat Peristiwa Transaksi ke Log |
| FR-03 | Menampilkan Isi Log |
| FR-04 | Membatalkan Transaksi Beserta Perubahannya |
| FR-05 | Memulihkan Basis Data ke Waktu atau Transaksi Tertentu |
| FR-06 | Membuat Checkpoint |
| FR-07 | Memulihkan Basis Data Otomatis setelah Crash |
| FR-08 | Menguji Pemulihan dengan Beberapa Transaksi |
| FR-09 | Driver Program Komponen |
