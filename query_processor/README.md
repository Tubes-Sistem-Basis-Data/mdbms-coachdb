# Query Processor (QP)

Implementasi oleh group QP (Group 5).

Facade: `QueryProcessor` di `common/interfaces/query_processor.py`.

## Requirement

| Kode | Judul |
| --- | --- |
| QP-01 | Client CLI & Query Execution |
| QP-02 | Manajemen Sesi dan Konkurensi Multi-Client |
| QP-03 | Menerjemahkan Query Plan |
| QP-04 | Mengevaluasi Ekspresi |
| QP-05 | Menampilkan Data (SELECT & FROM) |
| QP-06 | Menyaring Data (WHERE) |
| QP-07 | Menghapus Data (DELETE) |
| QP-08 | Menggabungkan Tabel (JOIN) |
| QP-09 | Mengurutkan Data (ORDER BY) |
| QP-10 | Menambah Data (INSERT) |
| QP-11 | Mengubah Data (UPDATE) |
| QP-12 | Menjalankan Transaksi (BEGIN, COMMIT, ABORT) |
| QP-13 | Membuat dan Menggunakan Index (CREATE INDEX) |
| QP-14 | Driver Program Komponen |
| QP-15* | Fitur Ekstra DDL (CREATE TABLE & DROP TABLE) |
| QP-16* | Fitur Ekstra Kueri (LIMIT, AS, Subquery) |

Kode bertanda `*` adalah bonus.
